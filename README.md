# 📈 Interactive Stock Price Analyzer

## Project Overview
This project is a Python-based stock analysis tool that retrieves stock market information and historical price data using Yahoo Finance.

It allows users to enter stock ticker symbols and visualize stock price movements alongside 7-day and 30-day moving averages.

## Features
- Retrieves company information and current stock prices.
- Downloads approximately one year of historical stock data.
- Calculates 7-day Moving Average (MA).
- Calculates 30-day Moving Average (MA).
- Visualizes stock prices and moving averages using Matplotlib.
- Supports interactive analysis of multiple stock symbols.

## Technologies Used
- Python
- Pandas
- Matplotlib
- yfinance
- Jupyter Notebook

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the imports cell followed by the main code cell.
5. Enter a stock ticker symbol (e.g., AAPL, MSFT, GOOGL).
6. Enter `Q` to exit the program.
